# Order Completion Test Cases

## Overview

This document contains the manual test cases created to verify the order completion functionality of the SauceDemo application.

The test cases cover completing an order with valid checkout information, verifying the order confirmation, and checking the application state after the order has been successfully completed. User-specific order completion behavior is also tested using the application's `error_user`.


## Test Cases

| Test Case ID | Requirement ID | Scenario ID | Scenario | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|
| TC-ORDER-001 | FR-ORDER-001 | TS-ORDER-001 | Complete an order using valid checkout information. | Order is successfully submitted. | Order was successfully submitted using valid checkout information. | **PASS** |
| TC-ORDER-002 | FR-ORDER-002 | TS-ORDER-002 | Verify the confirmation displayed after order completion. | Order confirmation page/message is displayed. | Order confirmation page was displayed with the message "Thank you for your order!" along with the order dispatch information and options to return home or generate a PDF order. | **PASS** |
| TC-ORDER-003 | FR-ORDER-003 | TS-ORDER-003 | Verify the application state after completing an order. | Application should return to an appropriate post-order state and allow the user to start a new shopping workflow. | After completing the order, the cart and shopping state returned to the initial pre-shopping state, allowing a new shopping workflow to be started. | **PASS** |
| TC-ORDER-004 | FR-ORDER-001 | TS-ORDER-004 | Verify order completion using error_user. | Clicking Finish on the Checkout Overview page should complete the order and display the order confirmation page. | Clicking Finish had no effect and the order was not completed. The Checkout Overview page remained displayed. | **FAIL** |

## Execution Note

All four order completion test cases were manually executed against the SauceDemo application.

The standard-user order completion scenarios passed successfully. The order was successfully submitted using valid checkout information, the expected order confirmation was displayed, and after order completion the shopping state returned to the initial state with the cart cleared.

User-specific testing with `error_user` identified an order completion failure. Clicking the Finish button on the Checkout Overview page had no effect, preventing the order from being completed.

This failure was recorded as a verified defect.
