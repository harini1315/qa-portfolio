# Login Test Cases

## Overview

This document contains the manual test cases created to verify the login functionality of the SauceDemo application.

The test cases cover both positive and negative scenarios, including successful login, invalid credentials, missing login information, and login attempts using a locked user account. The purpose is to verify that valid users can access the application and that invalid or restricted login attempts are handled correctly.

## Test Cases

| Test Case ID | Requirement ID | Scenario ID | Scenario | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|
| TC-LOGIN-001 | FR-LOGIN-001 | TS-LOGIN-001 | Login with valid credentials. | User is successfully logged in and reaches the Products page. | User successfully logged in and was redirected to the Products page. | **PASS** |
| TC-LOGIN-002 | FR-LOGIN-002 | TS-LOGIN-002 | Login with an invalid password. | Login is rejected and an appropriate error message is displayed. | Login was rejected and the message "Epic sadface: Username and password do not match any user in this service" was displayed. | **PASS** |
| TC-LOGIN-003 | FR-LOGIN-003 | TS-LOGIN-003 | Login with a blank username. | Login is rejected and required-field validation is displayed. | Login was prevented and the message "Epic sadface: Username is required" was displayed. | **PASS** |
| TC-LOGIN-004 | FR-LOGIN-003 | TS-LOGIN-003 | Login with a blank password. | Login is rejected and required-field validation is displayed. | Login was prevented and the message "Epic sadface: Password is required" was displayed. | **PASS** |
| TC-LOGIN-005 | FR-LOGIN-004 | TS-LOGIN-004 | Login using the locked/restricted user. | Application prevents successful access and displays the appropriate response. | Login was prevented and the message "Epic sadface: Sorry, this user has been locked out." was displayed. | **PASS** |
