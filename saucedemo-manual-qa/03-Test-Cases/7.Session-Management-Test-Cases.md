# Session Management Test Cases

## Overview

This document contains the manual test cases created to verify session and logout behavior in the SauceDemo application.

The test cases cover logging out from an authenticated session, verifying that authenticated pages cannot be accessed after logout, and navigating between supported application pages while remaining logged in.

## Test Cases

| Test Case ID | Requirement ID | Scenario ID | Scenario | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|
| TC-SESSION-001 | FR-SESSION-001 | TS-SESSION-001 | Log out from an authenticated session. | User is successfully logged out and returned to the login page. | User was successfully logged out and returned to the login page. | **PASS** |
| TC-SESSION-002 | FR-SESSION-002 | TS-SESSION-002 | Verify application state after logout. | Authenticated pages should not be accessible after logout. | Access to the authenticated inventory page was prevented and the message "Epic sadface: You can only access '/inventory.html' when you are logged in." was displayed. | **PASS** |
| TC-SESSION-003 | FR-SESSION-003 | TS-SESSION-003 | Navigate between supported application pages while logged in. | User remains in the expected authenticated session state. | User remained logged in while navigating between supported application pages. | **PASS** |
