# Product Test Cases

## Overview

This document contains the manual test cases created to verify the product listing and basic product interactions in the SauceDemo application.

The test cases cover product display, product information, sorting functionality, and adding products to the shopping cart. Testing was performed using both the standard user and the application's `problem_user` to verify expected behavior and identify user-specific defects.

## Execution Note

All seven product test cases were manually executed against the SauceDemo application.

The standard-user product scenarios passed successfully, including product display, product information, sorting, and adding products to the cart.

User-specific testing with `problem_user` identified two failures. All products displayed the same incorrect dog image instead of their corresponding product images, and the product sorting options did not reorder the product list as expected.

These failures were recorded as verified defects.
