# Checkout Test Cases

## Overview

This document contains the manual test cases created to verify the checkout functionality of the SauceDemo application.

The test cases cover entering checkout information, validation of required fields, reviewing order information, and cancelling the checkout process. Both positive and negative scenarios are included to verify that valid checkout information is accepted and missing required information is handled correctly. User-specific checkout behavior is also tested using the application's `problem_user` and `error_user`.

## Execution Note

All eight checkout test cases were manually executed against the SauceDemo application.

The standard-user positive and negative checkout scenarios passed successfully. Valid checkout information was accepted, required-field validation worked correctly for missing information, the order overview displayed the expected information, and the Cancel action returned the user to the Cart page while retaining the selected product.

User-specific testing identified two checkout failures. With `problem_user`, entering the Last Name also affected the First Name field. With `error_user`, the Last Name field did not accept keyboard input, although the application still allowed the user to continue to the Checkout Overview page.

These failures were recorded as verified defects.
