# Cart Test Cases

## Overview

This document contains the manual test cases created to verify the shopping cart functionality of the SauceDemo application.

The test cases cover adding products to the cart, viewing selected products, removing products, continuing shopping, and proceeding to checkout. The tests also verify that multiple selected products are displayed correctly in the cart. User-specific cart behavior is also tested using the application's `problem_user`.

## Execution Note

All six cart test cases were manually executed against the SauceDemo application.

The standard-user cart scenarios passed successfully. The cart correctly displayed selected products, allowed products to be removed, supported continuing shopping, allowed the user to proceed to checkout, and correctly displayed multiple selected products.

User-specific testing with `problem_user` identified inconsistent Add to Cart and Remove behavior. Certain products did not update their button state correctly, and adding or removing items caused inconsistencies in the cart counter.

This failure was recorded as a verified defect.
