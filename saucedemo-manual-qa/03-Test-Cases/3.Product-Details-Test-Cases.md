# Product Details Test Cases

## Overview

This document contains the manual test cases created to verify the product details functionality of the SauceDemo application.

The test cases verify that users can open a product details page, view the correct product information, and add a product to the shopping cart directly from the details page. Testing also includes user-specific behavior using the application's `problem_user`.




## Test Cases

| Test Case ID | Requirement ID | Scenario ID | Scenario | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|
| TC-DETAILS-001 | FR-DETAILS-001 | TS-DETAILS-001 | Open a product details page from the Products page. | Selected product details page is displayed. | Selected product details page was displayed successfully. | **PASS** |
| TC-DETAILS-002 | FR-DETAILS-002 | TS-DETAILS-002 | Verify product information on the details page. | Product name, price, description, and image correspond to the selected product. | Product name, price, description, and image were displayed correctly for the selected product. | **PASS** |
| TC-DETAILS-003 | FR-DETAILS-003 | TS-DETAILS-003 | Add a product to the cart from the details page. | Selected product is added to the cart. | Selected product was successfully added to the cart from the product details page. | **PASS** |
| TC-DETAILS-004 | FR-DETAILS-001 | TS-DETAILS-001 | Verify product-to-details navigation using problem_user. | Each product should open its corresponding Product Details page when selected. | Clicking the product names resulted in mismatched Product Details pages. Each selected product opened a different product's details page instead of its corresponding page. | **FAIL** |

## Execution Note

All four product details test cases were manually executed against the SauceDemo application.

The standard-user scenarios passed successfully. The selected product details page opened correctly, the expected product information was displayed, and products could be added to the shopping cart directly from the details page.

User-specific testing with `problem_user` identified a product-to-details navigation failure. Selecting product names opened mismatched Product Details pages instead of the corresponding product.

This failure was recorded as a verified defect.
