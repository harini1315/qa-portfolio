# Application Overview

## 1. Project Title
Swagger Petstore — Manual QA & API Testing Project

## 2. Application Under Test
Swagger Petstore is a sample REST API application that provides functionality for managing pets, store orders, and user accounts.

The application exposes REST API endpoints that can be tested through the Swagger interface and tools such as Postman.

## 3. Project Objective
The objective of this project is to gain practical experience in Manual QA and API testing while using commonly used QA tools.

The project focuses on:
- Manual functional testing
- Positive and negative testing
- API testing using Postman
- Defect tracking using Jira
- Basic browser DevTools investigation
- Integration and End-to-End testing
- Test execution and reporting
- Git/GitHub version control

## 4. Application Modules
The application is divided into three primary functional areas:

### Pet
The Pet module provides operations for managing pets, including:
- Creating a pet
- Retrieving pet details
- Finding pets by status
- Updating pet information
- Deleting a pet

### Store
The Store module provides operations related to inventory and orders, including:
- Viewing inventory
- Creating an order
- Retrieving an order
- Deleting an order

### User
The User module provides operations related to user accounts, including:
- Creating a user
- Logging in
- Logging out
- Managing user information

## 5. Testing Approach
Testing will be primarily manual and will focus on validating functional behavior and API responses.

The project will use the following tools:

| Tool | Purpose |
|---|---|
| Postman | API request execution and response validation |
| Jira | Defect reporting and tracking |
| Browser DevTools | Basic network/request investigation |
| Git/GitHub | Version control and portfolio documentation |

## 6. Scope

### In Scope
- Pet creation, retrieval, modification, and deletion
- Pet search/filter functionality
- Store inventory
- Store order creation and retrieval
- User creation and login/logout functionality
- Positive API testing
- Negative API testing
- HTTP status code validation
- Request and response validation
- Integration workflows
- Selected End-to-End workflows
- Defect reporting for genuine verified defects

### Out of Scope
- Automation testing (Selenium, Playwright, or Cypress)
- Performance/load testing
- Security penetration testing
- Advanced database testing
- Source-code testing
- CI/CD implementation
- Advanced programming
- Exhaustive testing of every API endpoint

## 7. Test Environment
- **Application:** Swagger Petstore
- **Testing Tools:** Postman, Jira, Browser Developer Tools, Git/GitHub


## 8. Important Testing Principle
All test execution results, defects, screenshots, metrics, and Jira references in this project will be based on actual testing performed during the project. 

No defects, pass/fail results, or metrics will be fabricated.
